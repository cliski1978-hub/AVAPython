# Triage labels

Local tickets record triage labels in their `Status:` line.

| Role | Label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Needs maintainer evaluation |
| needs-info | needs-info | Waiting for more information |
| ready-for-agent | ready-for-agent | Specified for autonomous implementation |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

When a skill references a triage role, use its mapped label.
Wayfinding execution states are defined in `issue-tracker.md`.
